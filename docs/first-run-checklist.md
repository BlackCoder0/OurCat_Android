# 手机端首次运行检查

完整步骤与待验收环境见[首次运行验收清单](https://github.com/BlackCoder0/OurCat_backend/blob/main/docs/first-run-checklist.md)。

手机侧重点记录：
- APK 是否正常安装，应用名是否为“OurCat 本地体验”。
- 后端地址保存后是否出现验证码；IP 应属于电脑，不是手机。
- 注册、登录、退出后切换地址是否符合提示。
- 图片选择器、相机权限和返回操作是否正常。
- 帖子图片与上报记录是否能够查看。
- 上报页是否明确展示示例位置说明。

目前的模拟器截图不能代替实体手机验收。反馈无需提供 IMEI、序列号、学校或个人地址。
